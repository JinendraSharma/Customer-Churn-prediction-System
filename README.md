# Customer Churn Prediction System

## Project Overview
This project is a Machine Learning based Customer Churn Prediction System built using Python.  
The model predicts whether a customer is likely to leave the company based on customer behavior and service-related features.

---

## Features
- Data preprocessing
- Missing value handling
- Feature encoding using One-Hot Encoding
- Logistic Regression model training
- Customer churn prediction
- Accuracy evaluation
- Data visualization using Matplotlib

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- VS Code

---

## Dataset Features
The dataset includes customer information such as:

- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Internet Service
- Online Security
- Tech Support
- Contract Type
- Payment Method
- Monthly Charges
- Total Charges
- Churn Status

Dataset Size:
- 7043 customer records
